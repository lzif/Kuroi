# Product Guide

## Initial Concept
A modern, high-performance anime scraper and streaming application built with Svelte 5, Tailwind CSS 4, and Cloudflare Pages/D1.

## Target Users
- **Indonesian Anime Fans**: Users looking for a single source for multiple Indonesian subs.
- **Mobile Viewers**: Users prioritizing fast, responsive experiences on mobile devices.
- **Archivers / Trackers**: Users building personal archives or tracking watch history.

## Core Features
- **Multi-source Streaming**: Unified streaming from multiple adapter sources.
- **Cloudflare D1 Caching**: High-performance metadata and episode list caching.
- **AniList Metadata**: Standardized titles, banners, and descriptions via AniList.

## Primary Use Cases
- **Watch Ongoing Anime**: Keep up with seasonal and currently airing shows.
- **Browse Catalog**: Discover new anime using AniList metadata and genres.
- **Search Capabilities**: Quickly find specific anime across multiple sources.

## Competitive Advantage
- **Speed & Performance**: Edge computing and optimized caching for fast load times.
